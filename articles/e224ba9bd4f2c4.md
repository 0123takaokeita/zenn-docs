## 手順


nvimのリポジトリ配置場所
```bash
cd .config/nvim

```
nvimのディレクトリ構成
僕はdotfilesでluaディレクトリだけ編集するようにしている。

```bash
$ ls -1

init.lua
lazy-lock.json
lua ⇒ /Users/takaokeita/dotfiles/nvim/astro/v4/lua
neovim.yml
README.md
selene.toml
```

astronvimはlazy.nvimを使っている。
lua/pluginsの中に個別のライブラリの設定を書けばloadすることができる。

```bash
$ tree nvim/astro/v4/

nvim/astro/v4/
└── lua
    ├── community.lua
    ├── lazy_setup.lua
    ├── plugins
    │   ├── astrocore.lua
    │   ├── astrolsp.lua
    │   ├── astroui.lua
    │   ├── liveserver.lua
    │   ├── mason.lua
    │   ├── none-ls.lua
    │   ├── previm.lua
    │   ├── treesitter.lua
    │   ├── user.lua
    │   └── wakatime.lua
    └── polish.lua
```
